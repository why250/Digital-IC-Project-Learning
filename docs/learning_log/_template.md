# 学习日志模板

返回 [日志使用说明](README.md)。复制后将标题替换为“日期 · Kxx · 工程问题”；下列空项由本人在实际学习时填写。

## Source / Connection

- 日期、资源 ID / 学期 / 版本：待填。
- 官方 Lecture / Lab / Reading 标题与具体链接：待填。
- 主节点 / 其他 K 节点、[本项目 Mapping](../references/course_mapping.md)、原课号 / workbook：待填。
- 当前项目 / 实验 ID：待填。
- 来源状态：公开可读 / 未核对 / 登录受限；本人状态：计划 / 已阅读 / 已实验 / 已解释。
- 本次想解决的问题、读之前的理解与预期：待填。

## Prediction

运行前写明：输入条件 → 预计波形/数值/寄存器/门/时序变化 → 哪种观察会否定预测。

列出 clock/reset、接口、位宽、负载/PVT 或模拟模型假设。至少预测一个边界或故障；不要在看到结果后回填成“运行前预测”。

## Experiment

- 实际状态：计划 / 已实现未运行 / 运行失败 / 通过（注明验证层次）。
- 独立 reference / stimulus / 检查器与故障注入：待填。
- Git revision、未提交差异、源码 SHA-256：待填。
- 工具版本、库/角/物理数据、参数/seed、执行命令：待填。
- 实际变化的一个因素与固定不变的比较条件：待填。

## Evidence

未运行时写 **未运行**；未获得的报告写 **未获得**。

- 层次：手算 / 数值模型 / RTL / 综合 / 物理 / AMS。
- 退出码、明确完成标记、用例/覆盖统计：待填。
- 产物位置、run_id、SHA-256、回放入口：待填。
- 预测与实际对照（单位/采样沿/时间基准）；失败与恢复：待填。
- 未覆盖的场景、例外/waiver、缺失数据：待填。

产物留 results/.tools，不提交波形、完整报告或专有工艺文件。自己的图表/解释应标来源与假设。

## Conclusion / What I Learned

预测哪里成立或被否定？本次改变了哪一个理解？解释 RTL 对应的 Q→逻辑→D、负载和时序窗口，或数字操作怎样影响模拟节点。

分别写出“当前证据支持什么”和“还需要哪些证据”。仿真通过不自动证明形式等价、MTBF、真实模拟性能或物理签核。

## Questions / Next Step

- 尚未解决的问题与替代解释：待填。
- 下一项可检验的小动作、需要的数据/工具：待填。
- 回原 workbook 的验收链接；仅在本人解释并验收后更新个人状态。
