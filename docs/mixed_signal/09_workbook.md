## 三个独立实验

| 实验 | 建议完成节次 | 核心验收 |
|---|---|---|
| power_sequencer | 25–28 | 顺序、MIN/MAX、ready、故障与 rearm |
| adc_measurement | 29–32 | acquisition、握手、标签、取消与背压 |
| block_average | 33–36 | 极值位宽、舍入、有效性与版本 |

先独立验证，再接校准 FSM；每个模块有独立 reference/monitor。后续实验不复用第一课 PASS 名称，不把课程目录当作已完成设计。

## 专项阶段门槛

- [ ] 25–28：接口契约有单位/域/默认值；所有等待有边界；故障输出与恢复明确。
- [ ] 29–32：采样与更新窗口正确；标签/epoch 不混淆；缓冲不无声覆盖。
- [ ] 33–36：极值/负数/half-tie/饱和通过独立数值参考；解释误差和滤波延迟。
- [ ] 37–40：搜索有前提和上限；快照/拥有权正确；成功与恢复证据完整。
- [ ] 41–44：独立模型、不变量、边界/随机用例、失败重放均有证据。
- [ ] 45–48 理论：功耗/电源/测试模式与数据依赖明确。
- [ ] 结课 RTL/综合：新项目的回归、映射与时序假设已审查。
- [ ] 可选工程阶段：物理/AMS/UPF/DFT/形式分别记录真实执行结果。
