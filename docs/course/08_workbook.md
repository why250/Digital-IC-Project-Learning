## 结课设计覆盖矩阵

| 类别 | 用例 | 期望 |
|---|---|---|
| 帧 | 0/1/23/24/25 个采样沿 | 仅合法 24 位事务有效 |
| 地址 | 合法/非法/RO 写/保留位 | 按地址表更新或报错 |
| 相位 | 外部边沿相位扫动 | 在声明窗口内无漏沿/位错 |
| 时间 | 最小高低宽度、CS/MOSI 窗口 | 满足规格时正确；违规有明确边界 |
| 提交 | pending 中再次 commit | 原快照保持，busy_reject |
| 快照 | commit 后改变 shadow | active 应用旧快照 |
| 应用 | safe_update 缺失/持续高 | 等待/下一合法边沿更新 |
| 同周期 | 新 commit 与旧应用 | 保守拒绝新提交 |
| 读回 | 读期间 active 更新 | 当前帧快照保持 |
| 状态 | W1C 与新错误同周期 | 新错误优先 |
| 复位 | 帧/提交/等待/应用各阶段 | 中止、默认状态、恢复 |
| 完成 | applied 宽度/次数 | 每次应用一次单周期脉冲 |

## 阶段门槛

- [ ] 阶段一：独立画波形和电路；错误注入被发现；恢复验证通过。
- [ ] 阶段二：解释网表；手算 setup/hold；约束来源清楚。
- [ ] 阶段三：定义域、稳定窗口、mailbox 和复位；配置快照一致。
- [ ] 阶段四：事务接受/拒绝明确；FIFO 边界正确；读懂 APB 等待。
- [ ] 阶段五理论：完成数据审查及全部计算题。
- [ ] 阶段五物理实验：具备配套数据，实际完成并保存实现证据。
- [ ] 阶段六：独立验证的 RTL/综合证据完整；评审达到学习门槛。
