# 学习路线

每一阶段只引入少量新概念，用真实工具和可检查的产物验证。

| 阶段 | 练习 | 核心概念 | 完成标准 |
|---|---|---|---|
| 01 | SPI Master，Mode 0，8 bit | 寄存器、非阻塞赋值、计数器、状态机、testbench | 看懂波形；发送接收和边界测试通过 |
| 02 | 同一 SPI 的 Genus 综合与时序 | Liberty、SDC、映射、setup/hold、slack | 能解释网表、面积、关键路径及约束假设 |
| 03 | SPI Slave + 配置寄存器 | 外部 SCLK、CDC、握手、原子更新、复位 | 安全更新多位模拟配置，验证异步时钟 |
| 04 | 小型数字模块布局布线 | LEF、floorplan、CTS、route、寄生与 STA | 使用可用且授权的库完成教学实现 |
| 05 | 数模接口 | 控制位毛刺、上电默认值、更新时机、电源域 | 明确模拟电路对数字接口的要求 |

后续阶段按学习进度开展。第一版不包含四种 SPI 模式、FIFO、总线接口、DMA 或流片签核。
教程使用库的结果不能移植为真实工艺结论。
